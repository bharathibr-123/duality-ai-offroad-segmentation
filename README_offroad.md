## 📌 Project Overview

This project trains a deep learning semantic segmentation model on **synthetic desert environment images** generated by **Duality AI's Falcon simulation platform**. The model classifies **11 distinct terrain classes** — including trees, rocks, sky, dry grass, logs, and more — to power real-time scene understanding for **Unmanned Ground Vehicle (UGV)** navigation in challenging, unstructured off-road environments.

The entire solution — from data pipeline to TTA inference and interactive demo — was designed, built, and submitted during the **BigRock Exchange Hackathon 2026**, earning a **Top 5** placement among all competing teams.

## 🚀 Getting Started

### Prerequisites

- Windows 10/11
- Python 3.9
- Miniconda or Anaconda
- GPU with CUDA 11.7+ (recommended) — CPU fallback supported

### Step 1 — Create & Activate Environment

```bash
conda create -n HACK python=3.9 -y
conda activate HACK
```

### Step 2 — Install Dependencies

```bash
pip install torch==2.0.1 torchvision==0.15.2 segmentation-models-pytorch albumentations opencv-python matplotlib tqdm
```

### Step 3 — Train the Model

```bash
python train.py
```

**Training outputs saved to `runs/`:**
- `runs/best_model.pth` — Best model checkpoint
- `runs/training_graphs.png` — Loss & IoU curves
- `runs/per_class_iou.png` — Per-class IoU bar chart

### Step 4 — (Optional) Resume / Fine-tune

```bash
python train_resume.py
```

## 🧠 Model Architecture

| Component | Detail |
|---|---|
| **Architecture** | DeepLabV3+ |
| **Backbone** | EfficientNet-B4 (ImageNet pretrained) |
| **Input Size** | 384 × 384 |
| **Batch Size** | 2 |
| **Epochs** | 40 + 20 (resume) |
| **Optimizer** | AdamW (LR = 3e-4) |
| **Scheduler** | CosineAnnealingWarmRestarts |
| **Loss** | Focal (γ=2) + Dice (40% weight) |
| **Mixed Precision** | Yes (GPU only) |

---

## ⚙️ Techniques Used

### Loss Function
- **Focal Loss** (γ=2) — focuses training on hard, rare examples
- **Dice Loss** — directly optimizes IoU-like overlap metric
- **Class Weights** — rare classes (Flowers, Logs) receive 5× higher weight to address class imbalance

### Augmentation Pipeline
- Horizontal/Vertical flip · RandomRotate90
- ShiftScaleRotate (scale ±10%, rotate ±15°)
- RandomBrightnessContrast · HueSaturationValue · CLAHE
- GaussNoise · GaussianBlur · MotionBlur
- CoarseDropout (random patch masking)

### Test-Time Augmentation (TTA)
- 8 augmentation variants per image
- 3 scales: 0.75× · 1.0× · 1.25×
- Weighted ensemble — original scale gets **60% weight**
- Flip-back correction applied to flipped variants

### Alternative Approach
- `train_segmentation.py` explores a **DINOv2 (ViT-based)** backbone as an alternative to EfficientNet-B4
